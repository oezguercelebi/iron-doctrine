# Frozen slice-1 seam proposal

Lead adopts MatchContract.cs, GameConfig.cs, CatalogIds.cs into src/Contracts and slice1.placeholders.json into data. No Godot imports, external packages, wall clock, or engine RNG in contract/sim. Plain .NET 8. Sim lane implements public sealed class IronDoctrine.Sim.MatchFactory : IMatchFactory with public parameterless constructor. Lead root creates `new MatchFactory().Create(config, config.CreateSetup())`. Client lane implements public IronDoctrine.Client.MatchClient : Godot.Node3D with `void Initialize(IMatch match, Func<IMatch> rematch)` called before AddChild. Client imports Contracts only. Factory implementation stays sim; root alone references both lanes.

Simulation advances one configured tick per Step; client accumulates elapsed time at Rules.TickRate, with bounded render catchup but no variable tick sizes. Config numeric fields are integer sim units; divide positions, ranges and radii by Rules.UnitsPerWorldUnit for metre-scale Godot X/Z. Map WidthCells/HeightCells and CellSize determine full extent. Models are metre-scale glTF with +Y up and -Z forward. Config model resource is direct, no inferred catalog identifier/model filename transformations.

Submit validates player ownership, shape and obvious prerequisites immediately, returns a human-readable short reason, and queues accepted commands for next tick in submission order. Sim revalidates execution against current world (target lost, insufficient cash, obstruction). AI submits the same orders using its own fog-filtered snapshot and public map/static config, never hidden current entity state. AI may explore known enemy start coordinates; it may only aim at currently visible or remembered buildings, not track hidden armies. No bonuses. AI timing/placement/composition numbers come from config. Setup includes eight slots; maps limit active starts, simulation loops active slots generally. Only aegis.vanilla can currently be played; unsupported active loadouts fail clearly rather than silently substituting. Full catalog ids/prefix space remains available separately.

Snapshots are detached values and read-only by convention; simulation must copy arrays both on input and output rather than retain mutable external arrays. Viewer gets only its own economic HUD. Own entities remain available including own contained infantry for exit controls. Visible enemies/allies expose appropriate health/vet. Enemy queues, rally, cargo, orders and other private fields must be redacted; remembered buildings retain last-seen public state. Hidden units are absent. Projectiles and attack events require LOS; voice events are viewer-owned. Radar permits minimap unit blips from visible entities only and never reveals new LOS. Client draws shroud black, fog dim, and remembered buildings dim without rendering hidden units. Snapshots contain current-tick events; client gathers them after every sim Step and deduplicates by tick/ordinal.

World origin is lower corner. WorldPoint X/Z are nonnegative; cell indexing is z * WidthCells + x. Config rectangles are half-open cell ranges; unspecified cells are ground. ter.unbuildable blocks footprint and ground path here. Starts are terrain tags, not build restrictions: legal forward bases are allowed. Default original map is mirrored 120 by 80 metres with two clear pads, three finite neutral docks, four garrisons and mirrored clutter rectangles. All docks always spawn even when a slot is closed; only occupied map starts spawn command/dozer.

Build ProductId names a building and ActorIds one dozer. Travel to site, reserve/debit cost once, create incomplete building, tie it to builder; one builder owns one active building. On builder death the incomplete building disappears without husk/refund. Capture at completion preserves role/HP but transfers ownership, cancels/refunds original owner queues and interrupts original builder links; garrison ownership changes only through entry into empty neutral or destruction/spill (no combat-drop). Completion of each built eco.dropoff yields its first free gatherer once; capture does not mint one again. Queue applies to trained units and up.capture. CancelQueue indexes snapshot queue, refunds original paid cost with configured percentage. Queue pause under low power may be implemented consistently for powered producers; defenses and radar must stop. Any surviving owned building, including an incomplete one, prevents elimination until removed; map.dock and neutral map.garrison do not count for a player. No army-elimination shortcut.

Enter ActorIds infantry and TargetId own transport or neutral/own garrison. Exit accepts container actors (all occupants) or own contained infantry; Position is desired unload point, checked for legal ground occupancy. Scout fires its own weapon and passenger weapons; gatherer transports without passenger fire. Garrison uses arm.garrison, fires from its container position, and spills surviving occupants only on destruction using configured spill HP percentage. Tank cannot hit arm.air; rocket missiles exist in snapshots until impact. ForceAttack accepts target (including friendly) or ground coordinate; crush hurts own/allied infantry. Veterancy indices follow Ranks array 0=unranked, 1=Veteran, 2=Elite, 3=Heroic; thresholds and bonuses only in JSON.

CanPlace is the view preview and must not reveal hidden building collisions. It uses revealed terrain/footprints plus ownership, known prerequisite and affordability checks. Execution checks full collision and rejects illegal placement without orphan/debit. If a hidden structure blocks the location, dozer approach/vision reveals it before creation. Placement/production rejection may report short local reason but must not produce invented catalog event ids. MatchEvent Id uses existing vo./fx. rows only. UI selection/control groups/hover/camera live exclusively in client; model definitions and role labels come from Config. Pause/resign/end/rematch UI do not access sim internals.

SeamConformance.cs is a framework-free frozen proof entry point `SeamConformance.Run(IMatchFactory, configPath)` for tests executable. It fails with a missing factory until sim exists, then tests actual next-tick construction and deterministic state, ownership rejection, initial fog/HUD, pause and resign. Sim lane adds substantive internal fixture regression tests for all mechanics and fair complete match, using its own test support rather than expanding this public seam. Lead records initial missing-factory red and final proof command. No feature implementation supplied by C.
